<H1>Quel's Micropad

A small, customizable 5-key macropad with a rotary encoder, powered by the Seeed Studio XIAO RP2040-DIP.
Designed for simple shortcuts and macros.

<H1>BOM
  
1. Seeed XIAO RP2040-DIP
2. 5 Cherry MX Mechanical Switches
3. 5 1N4148 Diodes
4. EC11 Rotary Encoder
5. 4 M3x16mm screws

<H1>Firmware
This macropad can run two firmwares:

- QMK
- KMK

<H1>Assembly

1. Solder diodes
2. Solder MX switches
3. Insert and solder the XIAO RP2040-DIP
4. Solder the rotary encoder
5. Attach switches + keycaps
6. crew the case together
7. Flash firmware (QMK/KMK)

<H1>Usage

Use it for streaming macros, Photoshop tools, coding shortcuts, volume knob, or gaming functions
Encoder can control volume, scrolling, timeline scrubbing, etc.
